# ONIMARU（`bossType: "sumo"`）

- 登場: ステージ5 YOZAKURA（ボス出現62秒、ステージ全体68秒）
- HP: 24（単一の本体判定） / 移動速度基準値: 5
- モチーフ: 土俵の力士
- ステージテーマ: `yokai`（雑魚敵・障害物も和風の専用ロースター）

## 移動・攻撃 — 相撲の取り組みを模した専用ステートマシン（`dashState`）

標準の奥行きパトロールは使わず、以下のステートを巡回する。ステート名自体が姿勢遷移も兼ねる。

1. **pacing**（1.6秒）: 左右に揺れながら土俵内を巡回。攻撃なし。
2. **salting**（0.7秒）: 移動を止め、左右の腕を「大きく」交互に上げる「塩を撒く」モーション。
   小さな腕振りではなく、肩からしっかり振り上げる、はっきり分かる動きにする。
   **この状態のときのみ攻撃を行う。**
3. **ready**（0.9秒）: 四股を踏むような「仕切り」演出。左右の脚を交互に上げ、わずかに上下する。攻撃・移動なし。
4. **charging**（0.6秒）: 突進の予兆。目や手のひらの発光が高速点滅（20Hzほど）し、
   突進先（プレイヤーの位置、Zはプレイヤーより少し奥）を決定する。
5. **dashing**（0.4秒）: 決定した位置まで加速しながら突進する。到達時に画面揺れが発生。
6. **slapping**（1.3秒）: 至近距離で腕を高速（14Hzほど）に振り回す張り手モーション。
   **この状態では弾は発射しない**（接触ダメージのみの純粋な圧力演出）。
7. **returning**（0.9秒）: 元の基準位置・接近範囲内のランダムなZへなめらかに戻る。
8. 再び **pacing** へ。

## 攻撃詳細

- **salting** 状態のときのみ、左右どちらかの手（交互）から塩（霧状の粒子9個）を放物線状に撒く。
- 塩は画面上部ぎりぎりまで届くくらい高く放り投げ、そこから大きな放物線を描いてプレイヤー側へ
  降ってくるようにする（低い山なりではなく、明確に「高く撒いている」と分かる軌道にする）。
- 発射間隔（saltingステート中）: 0.35秒。

## HP・フェーズ

HPパーセンテージによるフェーズ変化はない。単一の本体判定でHPが0になった時点で撃破。
