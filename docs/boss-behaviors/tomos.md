# TOMOS（`bossType: "tomos"`）

- 登場: ステージ2 VOID GARDEN（ボス出現60秒、ステージ全体65秒）
- HP: 30（6枚の花弁が5HPずつ保持、合計30） / 移動速度基準値: 6
- モチーフ: 花の怪物

## 移動

標準の奥行きパトロール（接近範囲 Z: -15〜-5）に加えて、ゆるやかなX方向の左右ドリフトを行う。

## 姿勢遷移

named pose のような明示的な姿勢ステートは持たない。6枚の花弁全体がゆっくり回転しつつ、
花弁ごとに開閉するような揺らぎアニメーションを常時行う。花芯の発光は、無防備状態になると強く輝く。

体を支える蔓（つる）は、静止しているどのタイミングでも止まらず、常にゆらゆらと揺れ続ける
（風に吹かれているような、緩やかで途切れないウェーブ状の揺れ）。花弁の開閉や移動の有無に関わらず、
この蔓の揺れは常時継続する。

## 攻撃

- 8方向に扇状に広がる弾（約126°の範囲に8発）を発射し、それぞれがプレイヤー付近の目標へ緩やかに誘導する。
- 発射間隔: 1.4秒（ボス標準間隔）。

## HP・フェーズ

HPパーセンテージによるフェーズ変化はなく、代わりに「花弁シールド」の段階がある。

## 固有ギミック — 花弁シールド

- 花芯を囲む6枚の花弁がそれぞれ5HPを持つ（合計30HP = ボスの全HP）。
- プレイヤーの弾は、生存している花弁のうち外側にあるものから順にヒットし、その花弁のHPを1減らす。
- 1枚でも花弁が生きている間は、弾は花弁に吸収され、花芯本体にはダメージが一切通らない。
- 全ての花弁のHPが0になって初めて花芯が無防備になり、以降は花芯へのヒットがそのままボスのHPを減らす。
- HPを失った花弁は非表示になる。
