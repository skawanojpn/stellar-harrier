# CERBERUS（`bossType: "cerberus"`）

- 登場: ステージ6 INFERNO CORE（ボス出現65秒、ステージ全体72秒）
- HP: 30（3つの頭が10ずつ保持、合計30） / 移動速度基準値: 7（ただし実質移動しない、下記参照）
- モチーフ: 炎を吐く三頭の番犬
- 見た目は3倍スケールで表示される

## 移動

**前後左右へ一切移動しない。** 標準の奥行きパトロールも使わない。

- スポーン時に接近範囲(Z: -30〜-19)内のランダムな1点にZ座標が固定され、以降Zは変化しない。
- Xも基準位置に固定されたまま。
- その場での足踏み（4脚の対角歩行アニメーション）と、頭ごとの上下ボブのみを常時行う
  （移動ではなくアイドルモーション）。

## 姿勢遷移 — named pose FSM

以下の4姿勢を順番に、なめらかに遷移しながら巡回する（"crouch" → "sit" → "stand" → "rear" → 最初に戻る）。

1. **crouch**（伏せ、1.8秒）
2. **sit**（座り、1.6秒）
3. **stand**（立ち、1.8秒）
4. **rear**（首をもたげる、1.4秒）

各姿勢は体の高さ・傾き、頭の高さ・傾きが個別に定義されており、遷移は0.6秒かけてイーズイン・アウトで
滑らかに変化する（前の姿勢のポーズから次の姿勢のポーズへ）。

## 攻撃

- 左→中央→右の順に頭を切り替えながら、生存している頭からプレイヤー狙いの単発ブレスを発射する
  （死んでいる頭はスキップされる）。
- ブレスは炎の魔獣らしく、球形コア＋周囲に纏った複数の小さな外炎パーティクルで構成される
  火炎弾（`spawnFlameBolt`、オレンジ系の二色）で、進行方向を軸にゆらめくロール回転をする。
- 発射間隔: **0.5秒**（全ボス中最速）。

## HP・フェーズ

HPパーセンテージによるフェーズ変化はない。3頭合計のHPが0になった時点で撃破。

## 固有ギミック — 頭部のみ被弾判定、3頭独立HP

- 全HP30は左頭10・中央頭10・右頭10に均等分割される。
- **当たり判定は頭部のみ**。胴体・首・脚は無敵（ダメージが通らない）。
- ダメージ判定は、着弾位置に**ワールドX座標が最も近い頭**に割り振られる（GODANIのZ座標基準とは異なる）。
- 頭のHPが0になると、その頭は非表示になる。
