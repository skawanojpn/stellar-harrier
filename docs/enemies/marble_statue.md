# 大理石像（`kind: "marble_statue"`）

- 登場: ステージ2 VOID GARDEN（西洋庭園に元々あった彫像が動き出したという想定）
- HP: 1 / スコア: 350 / 移動速度基準値: 16（全エネミー中では遅めの部類）
- メッシュ: `buildMarbleStatueMesh()`（size=1、**現在は暫定プレースホルダー**
  ——カプセル型の胴体＋球の頭部のみの仮メッシュ。最終的な見た目は
  「大理石のダビデ像のような敵」というコンセプトに基づき、
  `docs/gemini-agent-instructions.md`の指示に沿って別途差し替える予定）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用のゆっくりとした自転のみ行う。

## 攻撃

攻撃できない（接触ダメージのみ）。西洋庭園に佇む彫像というコンセプトに
合わせ、静的な障害物に近い近接型として設計されている。

## 既知の課題

- 見た目が暫定プレースホルダーのため、最終的な大理石像デザインへの差し替えが
  必要（`docs/gemini-agent-instructions.md`参照）。
- オービター（`dom`）が担っていたステージ2の枠を引き継ぐ形で追加された
  （`docs/stages/02-void-garden.md`参照）。
