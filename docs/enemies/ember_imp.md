# エンバーインプ（`kind: "ember_imp"`）

- 登場: ステージ6 INFERNO CORE
- HP: 1 / スコア: 230 / 移動速度基準値: 30
- メッシュ: `buildEmberImpMesh()`（size=1、逆さコーンの胴体＋半透明の
  丸い炎の羽根2枚）

## 移動

基準の汎用パターンに加え、`baseX`を自機の現在X座標へ`dt*1.5`の速さで
イージング追従させることで、自機の位置へダイブしてから通り過ぎて
撤退するような軌道を作る（実体としては横方向の緩やかなホーミング）。
移動中は0.08秒間隔で炎のパーティクル（`spawnParticleBurst`、オレンジ色、
2個/回、寿命0.3秒）を撒き、炎の軌跡を残す。

## 姿勢遷移

named pose のような姿勢ステートは持たない。

## 攻撃

攻撃できない（接触ダメージのみ）。ダイブ軌道そのものが脅威となる設計。
