# トモス兵（`kind: "tomos"`、雑魚版）

**注意**: これはボスのTOMOS（`bossType: "tomos"`、`docs/boss-behaviors/tomos.md`参照）とは
**別のキャラクター**。メッシュ・HP構造とも完全に独立しており（雑魚版は`buildTomosEnemyMesh()`、
ボス版は`buildTomosBossMesh()`）、混同しないこと。

- 登場: `tomosEnabled`フラグが立っているステージ（8, 10）。`enemyKinds`配列には現れず、
  ステージ設定の`tomosEnabled: true`によって出現が有効になる。
- HP: 1 / スコア: **未設定**（下記「既知の問題」参照） / 移動速度基準値: 26（グラント等より速い）
- メッシュ: `buildTomosEnemyMesh()`（size=0.6、小型の花モンスター）

## 移動

基準の汎用パターンに加え、顎の開閉アニメーション（`jawAngle = |sin(elapsedTime*10)|*0.6`で
上顎・下顎を開閉）を行う。移動速度は基準より速め。

## 姿勢遷移

named pose のような姿勢ステートは持たないが、上記の顎の開閉が常時のアイドルモーションとして機能する。

## 攻撃

攻撃できない（接触ダメージのみ）。

## 既知の問題 — スコア未設定

`scoreForEnemy(kind)`の明示的なスコアテーブルに`tomos`のエントリが存在しないため、
未定義キャラ用のフォールバック値（5000）が適用されている。これは全エネミー中で
突出して高いスコアであり、意図的な高得点設定なのか単なる設定漏れなのか要確認。
修正する場合は、他のYOZAKURA/ABSYMBEL系エネミーとバランスの取れた値（100〜300程度）を
明示的に設定することを推奨する。
