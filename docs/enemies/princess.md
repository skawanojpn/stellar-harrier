# 姫（`kind: "princess"`）

- 登場: ステージ5 YOZAKURA
- HP: 1 / スコア: 300 / 移動速度基準値: 22
- メッシュ: `buildPrincessMesh()`（平安鬼姫、size=1）

## 移動

基準の汎用パターンに加え、自身のメッシュに内蔵された`updateLoop(elapsedTime)`が
浮遊・袖や裾のなびき・扇の演出・鬼角の発光脈動・人魂の公転などを一括してアニメーションする
（詳細はメッシュ側の実装を参照。移動そのものは汎用のサインカーブ＋直進接近のまま）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記`updateLoop`による常時アニメーションのみ。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュには檜扇型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する
  （マズルはメッシュ内部の演出専用と思われる）。
- 発射間隔: 2.5秒（基準値）。
