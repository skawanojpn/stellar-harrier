# シェイド（`kind: "shade"`）

- 登場: ステージ10 ABYSS ZERO
- HP: 1 / スコア: 300 / 移動速度基準値: 24
- メッシュ: `buildShadeMesh()`（size=1、縦長の半透明球体＋ピンクの目）

## 移動

基準の汎用パターンに加え、`elapsedTime`と`wavePhase`から作る
サイン波で不透明度を常時脈動させる（0.25〜0.8の範囲）。透明度が下がる
タイミングで攻撃が来るように見えるが、実際の発射タイミングは
`fireTimer`（他の非ボス敵と同じ2.5秒間隔）に依存しており、
見た目の明滅と発射タイミングは厳密には連動していない
（今後の修正候補: 発射直前に必ず最も透明になるよう同期させる）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。

## 攻撃

- 汎用の直進弾（自機方向）を発射する。
- 発射間隔: 2.5秒（基準値）。
