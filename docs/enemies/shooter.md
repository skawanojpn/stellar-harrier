# シューター（`kind: "shooter"`）

- 登場: ステージ1, 2, 3, 4, 6（INFERNO CORE）, 8（ABSYMBEL）, 10（ABYSS ZERO）
- HP: 1 / スコア: 200 / 移動速度基準値: 22
- メッシュ: `buildGenericEnemyMesh(size, true)`（オレンジ色のicosahedron、グラントと同形状で色違い、size=1）

## 移動

基準となる汎用パターン（サインカーブの揺れ＋直進接近）のみ。個別の特殊な動きは持たない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用のゆっくりとした自転のみ行う。

## 攻撃

- プレイヤーへ向けた直進弾（発射時点の自機方向、追尾なし）を発射する。
- 発射間隔: 2.5秒（グラント以外の攻撃可能キャラの多くと共通の基準値）。
