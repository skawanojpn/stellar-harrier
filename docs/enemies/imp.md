# インプ（`kind: "imp"`）

- 登場: ステージ7 SWEETHEART GROVE
- HP: 1 / スコア: 150 / 移動速度基準値: 22
- メッシュ: `buildImpMesh()`（Geminiサブエージェント制作デザイン。ポップな
  マゼンタパープルボディ、輝く小悪魔のツノ、つり目、コウモリ皮膜羽、
  しなやかに揺れる矢印尻尾）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。ただし見た目は
メッシュ内蔵の`userData.updateLoop(time)`により、浮遊・コウモリ羽の
パタパタ羽ばたき・矢印尻尾の揺れが常時アニメーションする
（`updateEnemies`側で`en.kind === "imp"`の際に`updateLoop`を呼び出す形に
対応済み。マズルは持たない、純粋な近接型のメッシュ）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記の常時アニメーションのみ行う。

## 攻撃

攻撃できない（接触ダメージのみ）。近接型として設計されている。
