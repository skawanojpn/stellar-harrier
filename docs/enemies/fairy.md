# フェアリー（`kind: "fairy"`）

- 登場: ステージ7 SWEETHEART GROVE
- HP: 1 / スコア: 260 / 移動速度基準値: 22
- メッシュ: `buildFairyMesh()`（size=1）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用のゆっくりとした自転のみ行う。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュにはワンド型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する。
- 発射間隔: 2.5秒（基準値）。
