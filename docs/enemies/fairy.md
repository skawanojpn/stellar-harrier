# フェアリー（`kind: "fairy"`）

- 登場: ステージ7 SWEETHEART GROVE
- HP: 1 / スコア: 260 / 移動速度基準値: 22
- メッシュ: `buildFairyMesh()`（Geminiサブエージェント制作デザイン。スマートな
  頭身プロポーション、エメラルドチュニック、腰まで流れる長い髪、大サイズの
  4枚シアー羽、手持ち魔法ステッキ）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。ただし見た目は
メッシュ内蔵の`userData.updateLoop(time)`により、浮遊・4枚羽の高速羽ばたき・
ステッキの発光脈動が常時アニメーションする（`updateEnemies`側で
`en.kind === "fairy"`の際に`updateLoop`を呼び出す形に対応済み）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記の常時アニメーションのみ行う。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュにはワンド型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する。
- 発射間隔: 2.5秒（基準値）。
