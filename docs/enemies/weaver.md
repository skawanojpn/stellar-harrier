# ウィーバー（`kind: "weaver"`）

- 登場: ステージ6（INFERNO CORE）, 8, 10
- HP: 1 / スコア: 250 / 移動速度基準値: 20
- メッシュ: `buildWeaverMesh()`（size=0.7、複数の体節を持つ蛇型）

## 移動

大きく蛇行しながら接近する（波の振幅5.5、全エネミー中最大）。頭の動きに対して体の
各体節が位相遅れを持って追従し、蛇がうねりながら泳ぐような動きを表現する
（`sin(wavePhase - (体節番号+1)*0.8)*0.6`でオフセット）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。体節の追従うねりが常時アニメーションとして機能する。

## 攻撃

- 大きく蛇行しながら接近する分、弾は直進ではなくホーミング弾にする（見切りにくさのバランス調整）。
- 発射間隔: 2.5秒（基準値）。
