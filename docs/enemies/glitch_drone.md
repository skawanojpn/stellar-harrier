# グリッチドローン（`kind: "glitch_drone"`）

- 登場: ステージ4 CRYSTAL CANYON
- HP: 1 / スコア: 270 / 移動速度基準値: 16
- メッシュ: `buildGlitchDroneMesh()`（size=1、ネオンシアン発光の立方体＋
  マゼンタの単眼）

## 移動

基準の汎用パターンに加え、約1.5秒ごとに画面内のランダムなX/Y位置へ
瞬間移動する（連続移動ではなく、その場から次のフレームで座標が
飛ぶテレポート演出）。Z方向の接近速度自体は変化しない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。テレポート時にY回転が
わずかに加速する程度。

## 攻撃

- テレポート直後、自機方向への直進弾（シアン色、`0x00ffff`）を1発発射する。
- 発射間隔: 基本2.5秒だが、テレポートのたびに残り時間が0.15秒に
  短縮されるため、実質「テレポート→即発射」の挙動になる。
