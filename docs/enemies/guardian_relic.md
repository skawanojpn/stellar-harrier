# ガーディアンレリック（`kind: "guardian_relic"`）

- 登場: ステージ8 RUINS OF THE ANCIENTS
- HP: 2（`dom`と並び全エネミー中最高） / スコア: 450（全エネミー中最高） /
  移動速度基準値: 10（全エネミー中2番目に遅い）
- メッシュ: `buildGuardianRelicMesh()`（size=1.1、石造りの円柱頭部＋眉＋
  赤い目。MOAIボス（`barbarian`）の縮小版として意匠を揃えている）

## 移動

基準の汎用パターンのみ。低速・高耐久が特徴で、他の敵より長く画面内に
留まり続ける。

## 姿勢遷移

named pose のような姿勢ステートは持たない。

## 攻撃

- `spawnHomingMissile(pos, 0xcc9955)` で、石色のホーミング弾を1発放つ
  （MOAIボスとの意匠上の呼応）。
- 発射間隔: 2.5秒（基準値）。低速ホーミングだが、居座り時間が長いぶん
  発射回数が多くなりやすい。
