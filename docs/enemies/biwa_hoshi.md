# 琵琶法師（`kind: "biwa_hoshi"`）

- 登場: ステージ5 YOZAKURA
- HP: 1 / スコア: 280 / 移動速度基準値: 22
- メッシュ: `buildBiwaHoshiMesh()`（Geminiサブエージェント制作デザイン。
  モチーフを法師姿から「怨霊髑髏（がしゃどくろ）」へ刷新: 青い鬼火を
  眼窩に宿す巨大白骨髑髏、骨盤と大腿骨のフルスケルトン、正面に開く肋骨、
  顎の正面手前で抱える古琵琶。`kind`名・仕様（HP/スコア/移動/攻撃）は
  変更していない）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。ただし見た目は
メッシュ内蔵の`userData.updateLoop(time)`により、全身の浮遊・骨盤の
揺れ・眼窩の鬼火明滅・琵琶と骨腕の揺れ・周囲を漂う浮遊骨片が常時
アニメーションする（`updateEnemies`側で`en.kind === "biwa_hoshi"`の際に
`updateLoop`を呼び出す形に対応済み）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記の常時アニメーションのみ行う。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュには琵琶型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する。
- 発射間隔: 2.5秒（基準値）。
