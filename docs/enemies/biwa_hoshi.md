# 琵琶法師（`kind: "biwa_hoshi"`）

- 登場: ステージ5 YOZAKURA
- HP: 1 / スコア: 280 / 移動速度基準値: 22
- メッシュ: `buildBiwaHoshiMesh()`（size=1、琵琶を抱えた法師のデザイン）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用のゆっくりとした自転のみ行う。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュには琵琶型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する。
- 発射間隔: 2.5秒（基準値）。
