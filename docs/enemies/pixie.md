# ピクシー（`kind: "pixie"`）

- 登場: ステージ7 SWEETHEART GROVE
- HP: 1 / スコア: 180 / 移動速度基準値: 22
- メッシュ: `buildPixieMesh()`（size=1、妖精女王TITANIAの家来）

## 移動

基準の汎用パターンに加え、自身のメッシュに内蔵された`updateLoop(elapsedTime)`が
俊敏なピョンピョン・ホバリング・超高速の羽ばたき・魔法ステッキの揺らぎ・妖精の粉の公転などを
一括してアニメーションする（詳細はメッシュ側の実装を参照）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記`updateLoop`による常時アニメーションのみ。

## 攻撃 — 既知の問題

**現状、攻撃しない。** メッシュには星型トップの魔法ステッキと発射口（`userData.muzzle`）が
存在し、見た目上は弾を撃てそうなデザインになっているが、`canFire`判定の対象キャラ一覧に
`pixie`が含まれていないため、実際にはゲーム内で一切弾を発射しない（接触ダメージのみ）。
デザイン意図（ワンドを構えている）と実装（攻撃不可）が食い違っている状態のため、
将来的に攻撃を有効化する修正候補として記録しておく。
