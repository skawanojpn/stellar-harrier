# ダッシャー（`kind: "dasher"`）

- 登場: ステージ3（FROZEN NEBULA）, 4, 6, 8, 10
- HP: 1 / スコア: 150 / 移動速度基準値: 42（全エネミー中最速）
- メッシュ: `buildDasherMesh()`（size=0.55、最小サイズ）

## 移動

「直線的な高速突撃」がコンセプト。左右上下のうねりはほぼ無効化（振幅0.2、他キャラの
1/10以下）されており、ほぼ一直線にプレイヤーへ向かって突っ込んでくる。

## 姿勢遷移

named pose のような姿勢ステートは持たない。ただし速さを強調する演出として、機体を
Z軸方向にわずかに傾け（`sin(elapsedTime*8)*0.15`）、スラスターのマテリアル不透明度を
激しく明滅させる（`0.6 + |sin(elapsedTime*20)|*0.4`）。

## 攻撃

攻撃できない（接触ダメージのみ）。高速接近そのものが脅威となる近接特化型。
