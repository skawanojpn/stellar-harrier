# キューピッド（`kind: "cupid"`）

- 登場: ステージ7 SWEETHEART GROVE
- HP: 1 / スコア: 320（フェアリー系エネミー中最高） / 移動速度基準値: 22
- メッシュ: `buildCupidMesh()`（size=1）

## 移動

基準の汎用パターンに加え、自身のメッシュに内蔵された`updateLoop(elapsedTime)`が
浮遊・羽ばたき・弓矢の弦引き・ハートの脈動などを一括してアニメーションする
（詳細はメッシュ側の実装を参照）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記`updateLoop`による常時アニメーションのみ。

## 攻撃

- プレイヤーへ向けた直進弾を発射する。メッシュには矢型のマズル（`userData.muzzle`）が
  存在するが、実際の発射処理はこのマズル位置を参照せず、メッシュのルート位置から発射する。
- 発射間隔: 2.5秒（基準値）。
