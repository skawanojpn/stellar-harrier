# 河童（`kind: "frog"`）

- 登場: ステージ5 YOZAKURA
- HP: 1 / スコア: 120 / 移動速度基準値: 22
- メッシュ: `buildFrogMesh()`（Geminiサブエージェント制作デザイン。バンザイ
  ポーズの長い手と先端の扇形水かき、前傾姿勢、頭頂の光る神秘の水皿、
  周囲を旋回する水玉ビーズ）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。ただし見た目は
メッシュ内蔵の`userData.updateLoop(time)`により、ケロケロ跳ねる躍動・
バンザイの手のパタパタ・頭皿の水の脈動・周囲の水玉ビーズの公転が常時
アニメーションする（`updateEnemies`側で`en.kind === "frog"`の際に
`updateLoop`を呼び出す形に対応済み）。

## 姿勢遷移

named pose のような姿勢ステートは持たない。上記の常時アニメーションのみ行う。

## 攻撃

攻撃できない（接触ダメージのみ）。近接跳躍型として設計されている。メッシュには
くちばし先端にマズル用オブジェクト`userData.muzzle`があるが、`canFire`対象外の
ため未使用。

## 備考

`kind`の内部名は`frog`（英語で「カエル」）だが、実際のデザイン・ギャラリー表示名は
「河童」（頭に皿を持つ日本の妖怪）である。内部識別子のリネームは別項目（コード上の
管理名整理）で対応予定のため、現時点では`kind: "frog"`のまま据え置いている。
