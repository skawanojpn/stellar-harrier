# 河童（`kind: "frog"`）

- 登場: ステージ5 YOZAKURA
- HP: 1 / スコア: 120 / 移動速度基準値: 22
- メッシュ: `buildFrogMesh()`（size=1、緑の体に皿を頂く河童のデザイン）

## 移動

基準の汎用パターンのみ。個別の特殊な動きは持たない。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用のゆっくりとした自転のみ行う。

## 攻撃

攻撃できない（接触ダメージのみ）。近接跳躍型として設計されている。

## 備考

`kind`の内部名は`frog`（英語で「カエル」）だが、実際のデザイン・ギャラリー表示名は
「河童」（頭に皿を持つ日本の妖怪）である。内部識別子のリネームは別項目（コード上の
管理名整理）で対応予定のため、現時点では`kind: "frog"`のまま据え置いている。
