# スプライト（`kind: "sprite"`）

- 登場: ステージ1 FANTASY ZONE
- HP: 1 / スコア: 130 / 移動速度基準値: 18
- メッシュ: `buildSpriteMesh()`（size=0.4、光の玉に淡いグロー球を重ねただけの
  極小サイズ）

## 移動

基準の汎用パターンのみ。導入ステージの最初の一体として、他の敵より一回り
小さく・遅いことで「初めて見る敵」への警戒を煽らない役割を持つ。

## 姿勢遷移

named pose のような姿勢ステートは持たない。汎用の自転のみ行う。

## 攻撃

攻撃できない（接触ダメージのみ）。
